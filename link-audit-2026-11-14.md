## Notes

- Query URLs such as `/aplikasi?q=...` are intentionally absent from the sitemap (robots.txt disallows them) — they appear under "content not in any sitemap" only if some page links to them.
- `/_next/` asset URLs, the favicon, the PWA manifest and `/panduan/feed.xml` are checked as found in the HTML; they return 200 but are listed separately because they correctly do not belong in the sitemap.
- Orphan detection counts a link from any other crawled page (footer/nav included). A page linked only from itself still counts as orphan.
