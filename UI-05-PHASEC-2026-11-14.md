## 6. GuideCard reuse decision — left unchanged, deliberately

The audit's three copies are:
1. **`/panduan` hub** — type label (Cara/Penjelasan/Keamanan) + title + full `metaDescription`; `p-4`, `border-mist`, no CTA.
2. **ID homepage guides** — title + `metaDescription` + "Baca panduan →" CTA; `p-5`, `border-border`.
3. **EN homepage guides** — title + truncated `introEn[0]` + "Read the guide →" CTA; `p-5`, `border-border`.

They differ in 5 ways (type label, CTA presence and language, padding, border colour, description source). One shared component would need optional `typeLabel`, optional `cta`, and a padding/border variant — a 5-prop component to save ~8 lines of markup, touching 3 files, with real risk of visual drift in a component whose whole job is visual. The hub copy is intentionally denser (a list, not a teaser). Per the brief's "avoid unnecessary abstractions", **no GuideCard was extracted and no file was touched for this task**.
