## 2. Summary of every change

### 2.1 Design tokens (`tailwind.config.ts` + `src/app/globals.css`)

New Tailwind colours (all CSS-variable based, so they flip in dark mode):
- `border` — `--border`: light #E4E9F1, dark #24344F. Dedicated visible border colour (was: `mist` #F6F7F9, nearly invisible on white).
- `secondary` — `--text-secondary`: light #475569, dark #CBD5E1.
- `muted` — `--text-muted`: light #64748B, dark #94A3B8.
- `success` — `--success`: light #15803D, dark #4ADE80.
- `warn` — `--warn`: light #B45309 (unchanged), dark #FBBF24 (was static #B45309 in both modes).
- `danger` — `--danger`: light #B91C1C (unchanged), dark #F87171 (was static #B91C1C in both modes).

New `brand` scale (static hex, light-mode values from the approved proposal §2.1): 50 #E8F1FE, 100 #D6E6FB, 200 #A9CCF5, 500 #2E7DE0, 600 #1565D8, 700 #0F4FB0, 800 #0B4DA2, 900 #093D7D. Not used by any component yet — Phase D wires usage; dark-mode text usage should go through `primary-dark` (which already flips) until then.

Preserved unchanged: `primary` #1565D8 (+ `primary-dark` #0B4DA2, `primary-soft` #E8F1FE), `ink` #0B1F3A, `paper`, `mist`, font stack, `darkMode: ["class"]`, focus outline, reduced-motion rules, and the existing dark-mode amber/red one-off overrides (left as-is; Phase D replaces them with token-based callouts).

**Deliberate scope decision — `linkblue` NOT retired in Phase A.** It has 55 usages across 27 files. The brief forbids global replaces without checking every affected component; a 27-file replace belongs to Phase D, where each usage is checked. `linkblue` stays defined with a deprecation comment in the config. No component was re-coloured in Phase A.

### 2.2 Legal page typography (`.prose-legal`, `src/app/globals.css`)

The class was used by 11 pages and defined nowhere. It is now defined (unlayered CSS, so it wins over the pages' `text-2xl`/`text-lg` heading utilities by cascade + specificity; those utility classes remain as fallback):
- Container: `max-width: 48rem` (was: full 1024 px container — lines ran ~150 characters).
- H1: 32 px / 1.25, weight 800, letter-spacing -0.01em, margin-bottom 0.75rem.
- H2: 24 px / 1.33, weight 700, margin-top 2.25rem, margin-bottom 0.75rem.
- H3: 20 px / 1.4, weight 700, margin-top 1.75rem, margin-bottom 0.5rem.
- Paragraphs: 16 px (body base), line-height 1.625, margin-bottom 1rem.
- Lists: `ul` disc / `ol` decimal, 1.5rem left padding, 1rem bottom margin, items 0.375rem apart, muted markers.
- Links: `primary-dark` colour (flips to #60A5FA in dark mode), underline with 2 px offset, thicker on hover.
- `strong`: weight 700.
- Text colour inherits `text-ink` from the body, so light/dark themes work with no extra rules. The date line keeps its own `text-sm text-ink/60` styling.
- `space-y-4` was removed from all 11 `<article>` tags so spacing is controlled by the CSS alone (keeping it would have doubled paragraph gaps).
