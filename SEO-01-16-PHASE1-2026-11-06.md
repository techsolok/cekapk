## Phase 1.1 top-ups (same evening, 6 Nov 2026 — verified against live sources)

- **SEO-06, Kucing APK:** the audit found one unsupported number in the whole
  50-app catalog — "27 MB" on the Kucing page. Removed everywhere it appeared
  (`sizeLabel` → "Tidak terverifikasi"; section paragraph and feature reworded
  without the number). The page still says, honestly, that no official size
  can be confirmed.
- **SEO-06, Netflix:** `priceLabel` was "Berbayar — hanya tersedia lewat
  langganan resmi; tidak ada versi gratis resmi", which implied the app itself
  costs money to install. Fixed to "Gratis diunduh; konten memerlukan
  langganan berbayar" (the app is free to download; the subscription is for
  content). The focus text still correctly says there is no free content tier.
- **SEO-06, Lazada developer — audit flag REJECTED after a live check:**
  the audit suspected "Lazada Mobile" was wrong and the Play Store developer
  is "Lazada". Checked the live Play Store listing for
  `com.lazada.android` on 6 Nov 2026: the listing shows "More by Lazada
  Mobile" and the Play developer is Lazada Mobile. Stored value is correct;
  no change made.
- **SEO-15, SearchAction fixed for real:** the Phase 1 note said
  "/aplikasi?q= is a real search" — it was not: the catalog page ignored
  `?q=` entirely. `/aplikasi` now honours `?q=` (matches name, developer,
  tagline, category, plus the search-alias table, e.g. `?q=wa` → WhatsApp)
  and shows a result count with a "show all" link. The WebSite
  `SearchAction` target is now a working search. `robots.txt` still
  disallows crawling `/aplikasi?q=` so parameter URLs are not indexed.
- Regression script extended: `npm run check:seo` is now 11 checks
  (was 9) — the two new checks cover the "27 MB" removal and `?q=` support.
