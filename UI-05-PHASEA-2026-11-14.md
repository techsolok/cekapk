## 4. Task B — Contrast audit (before / after, re-measured on rendered pages)

**Method:** Playwright against the local Phase A build, computed `color` of each element + its effective background (composited up the DOM), WCAG ratio. **30 measurements (15 light + 15 dark), 0 failures.** Token values: `text-muted` light 4.76:1 / dark 7.37:1.

| Element (page) | Before (light) | After — light | After — dark |
|---|---|---|---|
| ID guide date line (`ink/55` 14px) | 3.79 FAIL | **4.76 PASS** | **7.37 PASS** |
| Breadcrumb (`ink/60` 14px) | 4.42 FAIL | **4.76 PASS** | **7.37 PASS** |
| Footer copyright (`ink/50` 12px) | 3.28 FAIL | **4.57 PASS** (footer bg is mist/60, slightly darker than white) | **6.38 PASS** |
| App identity meta — developer (`ink/60` 14px) | 4.42 FAIL | **4.76 PASS** | **7.37 PASS** |
| App identity meta — last checked (`ink/60` 14px) | 4.42 FAIL | **4.76 PASS** | **7.37 PASS** |
| OfficialButton note (`ink/55` 12px) | 3.79 FAIL | **4.76 PASS** | **7.37 PASS** |
| FactBox label (`ink/55` 12px) | 3.79 FAIL | **4.76 PASS** | **7.37 PASS** |
| AppTocAside label (`ink/50` 12px, desktop) | 3.28 FAIL | **4.76 PASS** | **7.37 PASS** |
| TikTok hint line (`ink/55` 12px, on ToolShell mist bg) | 3.79 FAIL | **4.60 PASS** | **6.56 PASS** |

| BottomNav inactive label (`ink/60` **11px**) | 4.42 FAIL | **4.76 PASS** | **7.37 PASS** |

All other changed spots use the same `text-muted` class on the same backgrounds (white paper, mist panels, dark paper) and were verified by the class change + the token ratios above: compatibility `<dl>` labels (ID + EN, ×8), EN guide related-apps developer / sources disclaimer / footer note, Instagram hint/uploader/result/preview notes (ID + EN, ×10), Permission Checker guidance, bandingkan date lines, kontak notes, perpustakaan meta/package lines, transparansi stat labels (×8), SearchBox result type label, DownloadInterstitial note.

**Replacement choice:** every fix is `text-muted` (the existing Phase A token) — no `text-secondary`, no new tokens, no layout/font-size/behaviour change. Dark mode stays readable (6.38–7.37 for the token on dark paper).

**Inspected and intentionally left unchanged:**
- `text-ink/65` occurrences (SearchBox "not found" line, TikTokTool loading-slow line, bandingkan, keamanan, panduan hub, perpustakaan): measured **5.26:1 light / 6.90 dark — passes AA**, so no change.
- FaqAccordion chevron SVG (`text-ink/50` in `ui.tsx:68`): a decorative icon, not text — non-text contrast requirement is 3:1 and it measures 3.28, so it passes as an icon.
- Admin files (`src/app/(id)/admin/**`, 6 occurrences): admin-only pages, outside the audit scope — left for a later pass if wanted.
- No `bg-ink/` / `border-ink/` / `divide-ink/` uses of /50|55|60 exist anywhere.

**Additional affected files found by the sweep (beyond the audit's 7):** BottomNav, SearchBox, TiktokTool, both Instagram tools, PermissionChecker, bandingkan (×2), kontak (ID + EN), perpustakaan (×2), transparansi — all fixed in this phase and listed in §1.
