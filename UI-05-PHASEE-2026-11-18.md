Only the APKPure guide was full. Phase E expands those 5 into full guides on the same pattern as the APKPure English guide (3,131 words, 13 sections, 7 FAQs).

## §2. What changed (exactly 2 files)

### 2.1 `src/lib/data/i18n-en-apps-b.ts` — the 5 guides

For each guide:
- `sectionsEn` added (3–4 sections; steps where the Indonesian guide has steps; a checklist where the content is a list of actions).
- `faqs` expanded from 3 to 4–5, taken from the Indonesian guide's own FAQs.
- `relatedAppsEn` added — only slugs from the 11 English app pages, so every link resolves (verified: all 7 linked pages return 200).
- `verifiedAtEn: "2026-11-18"` added — see §3.
- `bodyEn` set to `[]` (as APKPure already has): the old body paragraphs were folded into the new sections, so nothing was lost; the template renders `introEn` + sections when `sectionsEn` exists.
- `introEn` kept verbatim, except one correction in the ijo guide (see §2.3).
- Titles kept exactly as fixed in UI-05 Phase A.

Per-guide sections:
- **Hijau:** One Term, Many Different Meanings / Why Does This Term Go Viral? / The Risks of Downloading from APK Hijau Results / What to Do Instead (with a 5-item checklist).
- **Ijo:** What APK Ijo Means Depends on Who Says It / Why You Should Stop at the Explainer / If What You Really Want Is a Specific App / Why Colours Make Perfect Code Words.
- **Instal-aman:** Install Safely in Six Steps (numbered steps → HowTo JSON-LD) / Special Rules for APK Files from Outside Play Store (Sideloading) / Habits After Installing.

### 2.2 `src/app/sitemap.ts` — English guide lastmod (1 line)

The EN sitemap segment now passes each guide's `verifiedAtEn` as its lastmod:
`...enGuides.map((g) => u(`/en/panduan/${g.slug}`, 0.7, g.verifiedAtEn, "monthly"))`.
Result: the 5 expanded guides get lastmod 2026-11-18; APKPure keeps its real 2026-11-07. Other English entries are unchanged (still no lastmod). This follows the sitemap's own rule (SEO-10): lastmod only where a real review date exists.

### 2.3 Corrections made while expanding

- **Ijo intro, unsourced number removed.** The old intro said "Tens of thousands search for it monthly" — an unsourced volume claim. Rewritten without the number ("People usually search for it after seeing it on TikTok, X, Facebook, or WhatsApp, unexplained."). Same spirit as the Nov 17 audit fix, which removed unsourced numbers from the hijau guide.
- **Instal-aman meta description updated.** Phase A's text said "A short primer on installing Android apps safely" — wrong now that it is a full guide. New: "How to install Android apps safely: trusted sources, developer checks, Play Protect, and the rules for sideloading APK files." (125 chars). The other four meta descriptions were already accurate and are unchanged.

## §3. Verification-date rule — honoured

The binding rule from UI-05 Phase A: do NOT copy Indonesian `verifiedAt` values into `verifiedAtEn`; no fabricated dates; no misleading "Last checked" claims; no Article JSON-LD for thin summaries merely for schema coverage.

- `verifiedAtEn` is **"2026-11-18"** for all 5: the date this English edition was written and reviewed. It is NOT copied from the Indonesian `verifiedAt` (2026-10-18).
- Article JSON-LD now appears on these 5 because they are now full, reviewed guides — not for schema coverage. The thin state that justified withholding it no longer exists.
- APKPure English keeps its existing verified date (2026-11-07) and Article schema, untouched.

## §4. What was NOT changed

- **EN guide template untouched** — it already rendered sections, TOC, steps, checklists, FAQs, related apps, "Last checked" and Article/HowTo JSON-LD (proven by APKPure). No template change was needed.
- **Indonesian guides untouched** — same slugs, same content, same verified dates.
- **No `sourcesEn` added to the 5 guides.** The template's Sources section carries a hardcoded disclaimer about APKPure ("we have not independently tested APKPure's files") — wrong for other guides. These 5 need no external sources: they are explainers based on the verified Indonesian guides. Adding sources would have required a template change for one line.
- **No titles, URLs, canonicals, hreflang, or metadata changed** except the one instal-aman description in §2.3. No API, DB, auth, dependency, GA4, AnalyticsConsent, or SiteChrome change.
- **No other English pages touched.** EN app pages, EN trust pages, EN tools hub: unchanged.
